FROM SKETCH TO MOTION

A shared command catalog.
A clear path through your model.

01 / DESIGN

Build & edit

Sketch curves, offset and trim, then extrude, revolve, loft, sweep, fillet, and pattern. Work with parameters, components, and joints.

02 / INSPECTION

Understand the geometry

Inspect dimensions, topology, and assembly state. Check current-pose interference or sample it along a joint trajectory.

03 / MOTION

See how it moves

Preview coordinated rotation and slide tracks with easing and pauses. Replay once, loop, or ping-pong in an HTML player.

CADBOT, INSIDE FUSION

Describe the next operation.

The optional chat assistant uses the same finite command catalog as the terminal. Fusion executes CAD work on its main thread; a separate Python worker handles the AI conversation.

Design edits require an active CadBot message checkpoint. Read-only terminal commands work once the add-in is running.

“Offset this sketch by 2 mm, then inspect the resulting profiles.”Example prompt · Requires Fusion and optional Codex sign-in

VALIDATION YOU CAN READ

257 commands. Documented boundaries.

Release 0.5.0 records passing live cases for 251 commands and explicitly marks six unavailable paths. Host tests run on Linux and macOS; native Fusion validation used macOS and Fusion 2705.1.15.

Windows and native component animation authoring are not validated. Motion sampling is not continuous collision detection or a physics simulation. Passing cases do not certify every input geometry or option combination.
