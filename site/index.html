FROM SKETCH TO MOTION

A shared command catalog.
A clear path through your model.

01 / DESIGN

Build & edit

Sketch curves, offset and trim, then extrude, revolve, loft, sweep, fillet, and pattern. Work with parameters, components, and joints.

02 / INSPECTION

Understand the geometry

Inspect dimensions, topology, and assembly state. Check current-pose interference or sample it along a joint trajectory.

03 / MOTION

See how it moves

Preview coordinated rotation and slide tracks with easing and pauses. Replay once, loop, or ping-pong in an HTML player.

EXPLICIT DESIGN CHECKPOINTS

Model from your terminal.

Begin a named checkpoint, run typed CAD commands, then finish the boundary. Restore reverses that checkpoint and all later recorded edits, after verifying the document and native undo state.

Fusion executes CAD work on its main thread through an authenticated local bridge. Checkpoints are session-only and external edits can invalidate them.

fusion checkpoint begin --id plate
fusion design sketches create --name Base
fusion checkpoint finish
fusion checkpoint status

VALIDATION YOU CAN READ

261 commands. Documented boundaries.

Release 0.6.0 records passing live cases for 255 commands and explicitly marks six unavailable paths. Host tests run on Linux and macOS; native Fusion validation used macOS and Fusion 2705.1.15.

Windows and native component animation authoring are not validated. Motion sampling is not continuous collision detection or a physics simulation. Passing cases do not certify every input geometry or option combination.
