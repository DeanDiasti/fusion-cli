GET STARTED / macOS

Install fusion-cli.

Bring the terminal commands and optional CadBot assistant to your Autodesk Fusion installation.

Install with Homebrew

Use the project’s dedicated tap. This is a community package, separate from Homebrew core.

brew install DeanDiasti/tap/fusion-cli
fusion-install-addin

Homebrew installs the CLI and Python. The CLI and installer use Python’s standard library. The second command installs the add-in into your user’s Fusion AddIns directory, preserving the existing bridge token and backing up a previous installation.

Save your work, restart Fusion, then open Scripts and Add-Ins → Add-Ins → CadBot → Run.

Verify the installation

fusion help
fusion --version
fusion doctor
fusion design inspect

help and --version work offline. doctor checks the installed runtime and bridge authentication; it requires Fusion with CadBot running.

Upgrade

Save your work and stop CadBot before upgrading. Install the updated add-in before restarting it:

brew update
brew upgrade DeanDiasti/tap/fusion-cli
fusion-install-addin

Run fusion-install-addin after every upgrade. Homebrew does not modify a running Fusion installation automatically. Removing the formula does not remove your installed add-in, credentials, or conversations.

Requirements

  • macOS with Autodesk Fusion installed and licensed separately.
  • Homebrew for the tap installation, or Python 3.10+ for a source checkout.
  • No third-party Python packages or AI account are required.

Native validation used Fusion 2705.1.15 on macOS. Other Fusion versions need live revalidation. Windows installation is not validated.

Install from source

git clone https://github.com/DeanDiasti/fusion-cli.git
cd fusion-cli
python3 -m venv .venv
./scripts/install_addin.sh
./scripts/fusion help

Keep the checkout and virtual environment in place. Reinstall after source changes or moving the checkout. See the full CLI guide for setup, units, selectors, and recovery.

Keep the bridge local.

The authenticated bridge is a single-user loopback service. Do not forward its port or expose it to a network. Design edits and motion previews require an explicit CLI checkpoint.

Review the security and data policy before working with private designs.
