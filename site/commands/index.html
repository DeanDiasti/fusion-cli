REFERENCE / COMMAND-LINE CAD

Explore the command catalog.

Typed flags, explicit units, and offline help for Autodesk Fusion design, inspection, animation, and administration.

Start with offline help

fusion help
fusion design sketches offset --help
fusion design sketches trim --help
fusion design motion inspect --help
fusion --json design motion inspect --help

Help is resolved locally from the shared catalog. It works without Fusion and shows available selectors, required flags, and units. Add --json before the command for structured help.

Inspect a running design

fusion doctor
fusion design inspect

Start Fusion and run the CadBot add-in first. doctor checks authentication and the exact installed build. Inspection reads the active design through the bridge.

Design and assembly workflows

The catalog covers sketch arcs and splines, supported sketch projection/offset/trim, solid features, components, occurrences, joints, construction geometry, parameters, materials, and exports.

Begin an explicit checkpoint for edits. For example:

fusion checkpoint begin --id bracket
fusion design sketches create --name Outline
# Add sketch geometry and solid features.
fusion checkpoint finish
fusion checkpoint status
# Optional: undo the bracket checkpoint and later recorded work.
fusion checkpoint restore --id bracket

Commands use explicit entity selectors rather than guessing objects. Read the complete guide for flags, units, entity references, and checkpoint Design undo.

Motion and interference

Joint previews support rotation and slide tracks, easing, holds, and once/loop/ping-pong playback. Temporary motion poses use verified transaction rollback. Interference reports can inspect a static pose or sample along a trajectory.

Sampling can miss collisions between poses. These tools do not provide continuous collision detection, clearance certification, physics simulation, or automatic rigging. Native component animation authoring remains blocked.

Check support before relying on an operation.

0.6.0 has 261 canonical commands, with 255 commands covered by passing recorded live cases. Six paths are explicitly unavailable. Coverage is limited to the tested cases and build.
